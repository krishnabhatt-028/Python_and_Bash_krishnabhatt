# Python & Bash - DevOps Assignment

Core Python practice covering conditionals, dictionaries, and file handling.

## Tasks

| File | Description |
|------|-------------|
| `task1_grade_checker.py` | Takes a score and prints the grade (A-F) using if / elif / else |
| `task2_student_grades.py` | Menu-driven program to add, update and print student grades using a dictionary |
| `task3_write_file.py` | Creates `sample.txt` and writes content using `open()` and `write()` |
| `task4_read_file.py` | Reads and displays `sample.txt` using `file.read()` |

## How to Run

Requires Python 3.

    python3 task1_grade_checker.py
    python3 task2_student_grades.py
    python3 task3_write_file.py
    python3 task4_read_file.py

Run Task 3 before Task 4, because Task 4 reads the file that Task 3 creates.
